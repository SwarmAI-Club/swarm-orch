🐝 SwarmAI — 用戶流程 & API 流程

完整引導：由註冊 → 攞 token → 部署 → 接任務 → 賺 SWAI；以及背後成條 API 用邊個 call、點行。

🪙 Part A — 用戶完整流程

  1. 開戶 — 去 https://swarmai.club/portal/ → Sign up（email+password）→ 即派你條 X-Swarm-Token + node_id（client-xxx）。
  2. 準備模型 — 你部機開 llama.cpp：./llama-server -m Qwythos-9B-….gguf --port 8080 -ngl 99
  3. 部署 Worker（Docker，NAT 後都得） — 只填 3 樣：router 地址、token、node_id，用 --pull 淨係 outbound poll。 
    docker run -d --name swarm-worker \
  -e SWARM_ROUTER="https://swarmai.club/swarm" \
  -e SWARM_API_TOKEN="<token>" \
  -e SWARM_COMPLETION="http://host.docker.internal:8080/completion" \
  swarm-worker python worker.py \
    --router "https://swarmai.club/swarm" --token "$SWARM_API_TOKEN" \
    --completion "$SWARM_COMPLETION" --node-id "client-xxx" \
    --capabilities reasoning math code --pull --heartbeat 30
  4. 註冊 + 心跳 — Worker 上線 POST /register；之後每 30s 發 POST /status。瞓覺/空閒時行 IDLE_SHARING → 啟動 Proof-of-Uptime（賺 SWAI）。
  5. 接任務投票 — 客人開 /task，Router 派工：LAN node 被 push、你（NAT）用 poll 攞工 → 你部機跑 n_votes 次 → 交 /result。
  6. 賺 SWAI — 任務完成 /vote 自動照 gpu_min×10 mint；瞓覺 idle 照 min×2 mint。查額：GET /credits/<node> 或 portal 頁面。

工人嘅身份 = email（帳戶）；無需自架 router；唔需要 Tailscale；唔使開 port。

🔌 Part B — 成條 API 流程（順序）

  1. Auth — 除咗 /portal/signup|login，全部 call 都要 header X-Swarm-Token: <token>（無 → 401）。
  2. POST /register — worker 上線註冊（capabilities / model / url / pull flag）。
  3. POST /status — 每 30s 心跳；IDLE_SHARING 累積 uptime → Proof-of-Uptime。
  4. POST /task — 客人開工（prompt + capabilities + n_votes）→ Router 揀 node：
    　· LAN node → Router 直 POST <node>/assign（push）
    　· NAT node → 排入 inbox，等佢 GET /tasks/poll 攞。
  5. Worker 跑 votes → POST /result（含 content + confidence + duration_ms）。可 GET /results/:task_id 睇齊唔齊。
  6. POST /vote — Router 加權 majority（Σ confidence）→ 出 winner；同場每個 provider 按 gpu_min×10 自動 mint SWAI 入 data/ledger.db。
  7. 查帳 — GET /credits/:node · GET /ledger/latest · portal /portal/me（balance + journal）。

一齊行嘅例子（curl）

TOK=<你的 token>; R=https://swarmai.club/swarm
curl -s -H "x-swarm-token:$TOK" "$R/register" ...   # 選註冊
curl -s -H "x-swarm-token:$TOK" -X POST "$R/task" \
  -d '{"prompt":"…","required_capabilities":["reasoning"],"n_votes":3}'
# …等 workers 交 result…
curl -s -H "x-swarm-token:$TOK" "$R/results/<task_id>"
curl -s -H "x-swarm-token:$TOK" -X POST "$R/vote" -d '{"task_id":"…","beacon_id":"…"}'
curl -s -H "x-swarm-token:$TOK" "$R/credits/<node_id>"   # 睇 SWAI
